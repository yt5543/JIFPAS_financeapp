# JIFPAS Finance App（仮称: ミベルカーアプリ）

個人の資産（金融資産・不動産・現金）を統合的に「見える化」し、将来の資産目標とのギャップを提示する資産管理アプリ。JIFPA(S) PTE. LTD.（織田耕平氏）との協業構想プロジェクト。

## 背景・課題意識

- 家計簿アプリ（マネーフォワード等）はPL（毎月の収支）中心で、資産全体のBS（バランスシート）を統合的に見える化するものが存在しない
- 証券・不動産・保険・現金・現物資産をまたいだ統合管理ツールがない
- 「将来の資産目標を立てて運用する」という習慣自体を持たない人が多い

このアプリは、資産の現状を可視化し、将来目標（例: 65歳時点でいくら欲しいか）とのギャップに気づかせることを一次目的とする。

## 機能概要

### フェーズ1（MVP）— 資産管理・見える化

- 金融資産・不動産・現金の登録と一覧表示（BS管理）
- 不動産は「運用可能（賃貸中・貸出可能）」／「自宅（運用不可）」を区分でき、自宅は運用資産の集計から除外できる
- 「目標年齢（例: 65歳）」「目標金額」の設定
- 現状資産・年齢・目標額から、目標達成に必要な年利回りを逆算
- 積立入力（毎月の積立額）を加味した必要利回りの再計算

### フェーズ2 — 商品提案・リスク提示（要法務確認）

- 必要利回りが高い場合に、見合う金融商品を提案
- 商品情報は管理者側で管理する別データベース（商品マスタ）で運用
- ユーザーが商品を選択すると、その商品のリスク（元本保護有無、償還条件、発行体リスク、為替リスク等）を提示
- **重要な制約**: 高利回り海外商品の「推奨・勧誘」は金商法上の投資顧問業等に該当する可能性があるため、アプリは一貫して「資産管理・見える化・情報提示」の建前に留める。商品への誘導が必要な場合はJIFPAS側の海外IFA／投資顧問への相談導線につなぐ。★法務確認は未実施
