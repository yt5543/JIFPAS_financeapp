# SPEC — ミベルカーアプリ（仮称・資産見える化アプリ）

> Claudeとの壁打ち結果。認識齟齬をなくすための仕様書。
> ★は未確定・要確認事項。

## 受入条件（フェーズ1 MVP）
- [ ] ユーザーが金融資産・不動産・現金を個別に登録し、資産一覧（BS）として表示できる
- [ ] 不動産ごとに「運用可能（貸出可）」／「自宅（運用不可）」を設定でき、自宅は総資産の運用対象集計から除外される
- [ ] 「運用できる資産」と「運用できない資産」の合計がそれぞれ表示される
- [ ] 目標設定画面で「目標年齢（例: 65歳）」と「目標金額」を入力できる
- [ ] 現在の年齢・現状資産・目標額・目標年齢から、目標達成に必要な年利回り（複利）を自動計算して表示する
- [ ] 積立入力欄があり、「毎月の積立額」を加味した必要利回りの再計算ができる
- [ ] 計算結果を年1回など任意のタイミングで見直せる（前回入力値との比較ができる）

## 非目標（やらないこと・フェーズ1では対象外）
- 金融商品の自動連携（証券会社API等との自動同期）は行わない。手入力を前提とする
- 特定商品の推奨・勧誘は行わない（フェーズ2でも「情報提示」に留め、勧誘的な文言は出さない）
- 商品購入・口座開設等の取引機能は持たない
- 保険の詳細査定・不動産の自動査定（時価評価API連携）は行わない

## 仕様詳細

### 資産管理（BS）
- 資産カテゴリ: 金融資産（現金性資産／有価証券等）、不動産、現金
- 不動産には属性フラグ「運用可能」「自宅（運用不可）」を持たせ、集計ロジックで分岐する
- 資産ごとに「運用資産」「非運用資産」の二区分を持たせ、目標逆算計算には運用資産のみを使う

### 目標・逆算ロジック
- 入力: 現在年齢、目標年齢、現状の運用可能資産額、毎月積立額（任意）、目標金額
- 出力: 目標達成に必要な想定年利回り（複利計算、積立がある場合は積立を考慮した将来価値計算）
- 計算式（積立なしの場合）: 目標金額 = 現状資産 × (1 + r)^n　→ r について解く
- 計算式（積立ありの場合）: 積立を考慮した将来価値の公式で r を数値的に求める（解析解がないため二分探索等で近似）

### フェーズ2: 商品提案・リスク提示
- 商品マスタ（管理者側で管理）: 商品名、想定利回り、通貨、元本保護有無、期間、リスク種別（発行体リスク／為替リスク／流動性リスク等）、ステータス（募集中／終了）
- ユーザー側: 逆算で出た必要利回りに近い商品を一覧表示 → 選択すると当該商品のリスク詳細が表示される
- 表現規制: 「推奨」ではなく「参考情報の提示」であることが分かる文言・UI設計にする（★法務確認後に文言を確定）

## 例外・境界ケース
- 目標年齢が現在年齢以下、または目標金額が現状資産以下の場合 → 必要利回り0%（または「既に達成」表示）
- 運用可能資産が0円で積立もない場合 → 逆算不能（達成不可）である旨を明示
- 必要利回りが非現実的に高い数値（例: 20%超）になった場合 → 警告表示＋「積立額や目標年齢の見直し」を提案する導線を出す
- 不動産の運用可否フラグを後から変更した場合、過去の逆算結果は再計算が必要になる旨を明示する

## テスト・検証方法
- 織田氏MTG記載の試算例（元手1,000万円→65歳1億円、30歳/40歳/50歳スタート）を使い、逆算ロジックの計算結果が一致することを確認する
- 積立ありのケースについても手計算またはスプレッドシートでの検算と一致することを確認する
- 自宅フラグ付き不動産が運用資産集計から正しく除外されることをユニットテストで確認する
