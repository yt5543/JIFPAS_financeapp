# PLAN — ミベルカーアプリ（仮称・資産見える化アプリ）

> この案件でやりたいことを音声入力でダンプする場所。
> まず10分くらい喋って、やりたいこと・背景・前提条件を全部出す。

## 背景・目的
- JIFPAS 織田耕平氏との協業構想（2026-08-05 MTG）が発端。「AIで個人の資産管理（バランスシート）を見える化できないか」という提案。
- 家計簿アプリ（マネーフォワード等）はPL（毎月の収支）中心で、BS（資産全体のバランスシート）を統合的に見える化するものが存在しない。証券・不動産・保険・現金・現物資産をまたいだ統合管理ツールがない。
- 目的は「金融コミュニティのフロントになるサービス」。通信（オンライン）向け。ユーザーに自分の資産の現状を可視化させ、将来目標（65歳時点でいくら欲しいか）とのギャップに気づかせることが一次目的。
- 「目標を立てて資産運用する」という習慣自体を持たない人が多いという課題意識があり、まずその習慣を作ることが狙い。

## やりたいこと

### フェーズ1（MVP・資産管理の建前に留める）
1. **資産の見える化（BS管理）**
   - 金融資産、不動産、現金など保有資産を入力・一覧化
   - 不動産は「運用可能（賃貸中・貸出可能）」か「自宅（運用不可）」かを設定でき、自宅は資産計算から除外できる
   - 運用できる資産／できない資産を分けて集計する機能
2. **将来目標の設定**
   - 「65歳時点でいくら欲しいか」等、年齢と目標金額を設定できる場所を用意
3. **目標までのギャップ逆算**
   - 現状資産・年齢・目標額から、目標達成に必要な年利回りを逆算
   - 積立入力欄を設け、「資産運用＋毎月いくら積み立てるか」を加味した必要利回り計算にも対応
   - 参考（織田氏MTGでの試算例）:
     | 元手1,000万円→65歳で1億円 | 運用期間 | 必要利回り |
     |---|---|---|
     | 30歳スタート | 35年 | 約6.8% |
     | 40歳スタート | 25年 | 約9.7% |
     | 50歳スタート | 15年 | 約25%（非現実的） |

### フェーズ2（高利回り時の商品提案・要法務確認）
1. 逆算結果が高利回り（例: 年25%等）の場合、それに見合う金融商品を提案する機能
2. 商品情報は別データベース（管理者側で更新する商品マスタ）で管理。ユーザー一覧には常に最新の商品が出るようにする
3. 管理者側の商品管理画面（商品の追加・更新・リスク情報の登録）
4. ユーザーは必要利回りに対して提案された商品を選択すると、その商品のリスク（元本保護の有無、償還条件、発行体リスク、為替リスク等）が提示される
5. ★重要な法規制上の制約（要法務確認・織田氏MTGでの認識）:
   - 高利回り海外商品を自社が直接「推奨・勧誘」すると金商法上の投資顧問業等に該当する可能性がある
   - フェーズ1〜2を通じて、アプリの建前は一貫して「資産管理・見える化」に留める
   - 高利回りニーズが出たユーザーは、JIFPAS側の海外IFA／投資顧問（Fidelis等）への相談導線につなぐ形が現実的
   - 商品の推奨をせず情報提示・比較に留める設計であれば規制対象外という認識だが、★法務確認は未実施

## 前提条件・制約
- 期限・予算: 未確定（協業は構想フェーズ。契約・費用の話にはまだ至っていない）
- 規制上の制約: 上記フェーズ2の法規制リスクにより、商品の「推奨」ではなく「情報提示」に留める設計が必須
- リスク許容度は個人差が大きい（生活水準・家族構成・居住地域で必要額が変わる）→ 一律の運用提案ではなく個別条件を反映できる設計が必要
- 商品情報（利回り想定・リスク）は当面手入力でよい（自動連携は不要）
- 年1回程度の見直し（進捗確認・上振れ下振れの把握）ができる導線があるとよい
